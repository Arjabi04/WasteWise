♻️ WasteWise Backend
This is the backend service for WasteWise, a smart waste management platform.
providing REST APIs for:
- User Authentication
- Waste Pickup Scheduling
- Pickup Requests by Users
This service enables efficient communication between residents and waste collectors through secure and scalable API endpoints.


Backend Features
RESTful APIs for WasteWise app
User registration, login, and role management
Waste pickup scheduling for:
  Biodegradable
  Non-biodegradable
  Recyclable
Email notifications using Nodemailer + Mailtrap
MongoDB integration with Mongoose

⚙️ Tech Stack
Node.js with Express.js
MongoDB (with Mongoose)
Nodemailer for emails
Mailtrap for email testing
Render for deployment
